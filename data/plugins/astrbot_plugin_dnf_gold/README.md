DNF 金价插件（dnf_gold）
========================

功能概述
--------

- `/查金价`：查询 DNF 金价与走势图  
  - 无参数时默认查询 `K3A`（跨三A）  
  - 示例：`/查金价 K3B` 查询跨三B
  - 支持时间范围：`/查金价 最近几个月`、`/查金价 K3A 90天`、`/查金价 跨三A 3个月`
- 价格走势图  
  - 默认展示最近 7 天（168 小时）数据，采用与控制台消息趋势图接近的线形加面积风格  
  - 指定时间范围时，会展示对应区间走势、涨跌变化、均值区间与月均摘要
  - 数据不足指定范围时，自动按现有数据缩放时间轴，并提示“数据收集进行中”  
  - 单位为「万金币/元」
- AI 文本分析  
  - 在群聊中使用 `/查金价` 时，会调用已配置的 LLM 对当前价格与预测结果进行 2-3 句中文分析和风险提示
- 运行状态  
  - `/查金价状态`：查看采样成功率、最近采样日志与存储占用
- 每日定时播报  
  - 每天指定时间（默认 8 点整）在白名单群聊中自动播报一次金价与走势图  
  - 播报时会调用 `mem_chat` 插件的人格，通过 `persona_share` 结合图像进行人格化转播

依赖说明
--------

- 需要本机存在 Node 环境，并在 `~/astrbot-dnf-gold` 下部署并构建 TypeScript 项目  
  - 项目构建：在 `~/astrbot-dnf-gold` 内执行 `npm install` 与 `npm run build`  
  - 插件调用脚本：`npm run astrbot:report -- --zone=跨三A`
- 数据抓取来源：`yxdr` 与 `d173` 两个站点的报价页面  
  - 使用简单过滤与加权平均算法对样本进行清洗与汇总，计算当前万金价格与预测点
- 采样与存储  
  - 每 3 小时自动采样一次并记录毫秒级时间戳  
  - 数据存储为 SQLite 时序表，自动清理超过 365 天的数据  
  - 每日自动备份数据库到 `data/plugin_data/dnf_gold/backups`

配置方式
--------

插件启动后会在 AstrBot 数据目录创建配置文件：

- 路径：`{astrbot_data_path}/config/astrbot_plugin_dnf_gold_config.json`
- 字段说明：
  - `default_zone`：默认查询大区代码，默认 `"K3A"`  
  - `broadcast_hour`：每日播报小时（本地时间 0-23），默认 `8`  
  - `broadcast_enabled`：是否开启每日播报，默认 `true`  
  - `broadcast_groups`：需要每日播报的群号列表（字符串数组）

大区代码与展示名称
------------------

- `"K3A"` → `"跨三A"`  
- `"K3B"` → `"跨三B"`  

当 `/查金价` 无参数时，以配置文件中的 `default_zone` 为准。

使用说明
--------

- 在目标群聊中发送：
  - `/查金价`：使用默认大区  
  - `/查金价 K3A` 或 `/查金价 K3B`：指定大区
  - `/查金价 最近几个月`：默认大区近 3 个月走势
  - `/查金价 K3A 90天` 或 `/查金价 跨三A 3个月`：指定大区与范围
- 状态与诊断：
  - `/查金价状态`：查看采样成功率、最近采样日志、存储占用
- 为了使每日播报能够正确通过 `mem_chat` 进行人格转播，建议在每个需要播报的群聊中至少手动执行一次 `/查金价`，以便插件记录群号与平台信息。
